# 🌟 Элитная парикмахерская «Lumiere»

Добро пожаловать в репозиторий официального сайта парикмахерской **Lumiere**!  
Проект представляет собой многостраничный веб-сайт на PHP с поддержкой бронирования, управления услугами, мастерами и клиентами через базу данных.

---

## 📌 Основные возможности

- 💇‍♀️ Просмотр списка **услуг** с описаниями и ценами  
- 👨‍🎨 Информация о **мастерах**: специализация, расписание, ставка  
- 📅 Система **онлайн-записи** на услуги  
- 📞 Страница **контактов** с информацией о салоне  
- 🔐 Админ-панель (`/admin/login.php`) для управления контентом  
- 📐 Адаптивный дизайн, удобный на всех устройствах

## 🛠️ Технологии

- **PHP 8.3** — основной язык бэкенда  
- **MySQL** — реляционная база данных  
- **HTML5 + CSS3** — семантическая вёрстка и стили  
- **JavaScript** — для интерактивных элементов  
- **Nginx** — веб-сервер в локальной среде

## 🚀 Запуск локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MaXwel25/Lumiere.git
   cd Lumiere

2. Установить все необходимые технологии:
    ```bash
    sudo apt install -y nginx mysql-server php

3. Скопировать nginx.conf в следующую директорию и запустить (поменять расположение проекта, если требуется):
    ```bash
    cd /etc/nginx/sites-enabled
    sudo systemctl start nginx

4. Запустить скрипт db.sql для установки в MySQL (данные пользователя и пароль можно поменять):
    ```bash
    source /путь к проекту/Lumiere/config/db.sql

5. Откройте в браузере:
    ```bash
    http://localhost
